🎟️ Lottery Simulator

A Python-based Lottery Simulator that evolved from a simple raffle prize picker into a complete lottery company simulation system.
This project was built while learning Python and focuses on randomness, data structures, simulation logic, and business calculations.

---

Features:

Manual Mode

- Add participants manually
- Generate unique ticket numbers
- Purchase multiple tickets
- Run lottery draws
- Display winners and prize amounts

Simulation Mode

- Automatically generates 1000 players
- Assigns random ticket counts (1–5 tickets per player)
- Generates ticket numbers automatically
- Runs the complete lottery system without user input
- Displays final winners and statistics

Lottery Company System

- Calculates revenue from ticket sales
- 70% of revenue allocated to prize pool
- 30% retained as company profit
- Final business summary report

---

Project Evolution:

V1.0 - Raffle Prize Picker

- Randomly selects winners from participants
- Basic prize distribution

V1.1 - Lottery System

- Unique ticket numbers randomly generated (1-100)
- Random prize shuffling for fair distribution
- Winner ticket number displayed with prize announcement

V1.2 - Prize Distribution

- Fixed prize pool of $1000
- 50% / 30% / 20% payout structure
- Grand Prize, Second Prize, Third Prize structure
- Prize amounts displayed with winners

V1.3 - Multiple Ticket Support

- Participants can own multiple tickets
- Each ticket costs $100
- Prize pool dynamically calculated from ticket sales
- Winning ticket randomly selected from player's ticket list
- Increased winning probability based on ticket count

V1.4 - Real Lottery Draw

- Lottery winners selected from ticket pool
- More realistic drawing process
- Players choose their own ticket numbers (1-99)
- Duplicate number prevention
- Winning number drawn from pool of purchased tickets
- Winner identified by matching ticket number
- Input validation (ValueError handling)
- Range validation (1-99)

V1.5 - Lottery Company Simulator

- Company branding and welcome screen
- Revenue calculations
- Prize pool calculations
- Company profit calculations
- Business summary report

V1.6 - Auto Simulation Mode

- Manual and Simulation modes
- 1000 auto-generated players
- Random ticket assignment
- Automated lottery execution
- Complete simulation reports
